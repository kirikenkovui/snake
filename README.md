🐍 Snake Game

A classic Snake game built in pure JavaScript, HTML, and CSS with modern features.

## Features

- **Keyboard Controls**: WASD or Arrow keys
- **Mobile Support**: Touch swipe gestures for mobile devices
- **Multiple Difficulty Levels**: Slow, Fast, Very Fast, and Turbo modes
- **Live Score Display**: See your current and high score during gameplay
- **High Score Persistence**: Your best score is saved locally
- **Pause/Resume**: Pause the game anytime and pick up where you left off
- **Responsive Design**: Works on desktop and mobile devices
- **Speed Acceleration**: Game gets faster as you eat more apples

## How to Play

1. Choose a difficulty level to start
2. Use **WASD** or **Arrow Keys** to control the snake
3. On mobile, **swipe** in the direction you want to move
4. Eat the red apples to grow longer and increase your score
5. Avoid hitting the walls or your own body
6. Press **Pause** to pause the game
7. Try to beat your high score!

## Game Modes

- **Slow**: 200ms speed, normal acceleration (0.8x)
- **Fast**: 100ms speed, normal acceleration (0.8x)
- **Very Fast**: 50ms speed, normal acceleration (0.8x)
- **Turbo Mode**: 200ms speed, faster acceleration (0.6x) - Speed increases faster!

## Technical Stack

- Pure JavaScript (ES6+)
- HTML5 Canvas for graphics
- CSS3 with variables and responsive design
- Local Storage for persistence
