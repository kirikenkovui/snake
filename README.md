   🐍 Snake Game


Simple snake game in right in web browser

Features:
  Keyboard controls
  Different levels of difficulty
  Score
  Deathscreen

This project was made in pure JavaScript, with additional CSS. 


Open in browser: [https://kirikenkovui.github.io/snake/snake/index.html]
